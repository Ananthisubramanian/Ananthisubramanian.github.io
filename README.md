# Ananthi S Portfolio — Version 2

Interactive static portfolio based on the supplied resume.

Interactive features:
- Project filtering by AEM / WordPress / Shopify / PHP
- Clickable project case-study modal
- Keyboard-accessible project cards
- Interactive skill categories
- Responsive mobile navigation
- Reading progress bar
- Resume download
- LinkedIn and email actions

## Deploy to Vercel
1. Extract this ZIP.
2. In Vercel, open your existing project and deploy/import these files, or create a new project.
3. Framework preset: Other / static.
4. Build command: leave empty.
5. Output directory: leave empty.


## Project screenshots
Website screenshots supplied by the user are included as visual project previews. Projects without a directly matching supplied screenshot remain text-only.
